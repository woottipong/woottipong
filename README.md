# Woottipong Boonma

I build practical AI and developer tools for Thai-language speech, real-time media, and reliable infrastructure.

My public work spans live transcription and captioning, VTT generation, multimodal AI, registry and certificate operations, and performance experiments across Go, TypeScript, Python, Rust, and Zig.

## What I build

- 🎙️ **Real-time speech systems** — LiveKit/WebRTC pipelines for transcription, translation, caption review, and external feeds.
- 🇹🇭 **Thai-language AI workflows** — speech recognition, language detection, subtitle formatting, text-to-speech, and image analysis.
- ⚙️ **Developer infrastructure** — self-hosted tooling, certificate automation, Docker-based services, and security-focused backend design.
- 📊 **Systems experiments** — reproducible benchmarks that compare runtime and language trade-offs on practical workloads.
